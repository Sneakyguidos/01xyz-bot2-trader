Automated grid-trading engine for \[01.xyz](https://01.xyz ) perpetuals – farms airdrop points while staying liquidation-safe.



\## Features

\- Interactive CLI with live market list  

\- Auto-grid creation (maker-only, 0.01 % fee)  

\- Real-time fill tracking + front-run large orders  

\- Liquidation-protection simulation  

\- 24/7 loop with graceful shutdown  

\- Reads Bot-1 rankings for auto-market selection  

\- Full CI/CD, Docker, MIT license



\## Quick Start
